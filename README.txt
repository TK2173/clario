CLARIO — интерактивный образовательный прототип
================================================

Файлы:
- index.html — структура страницы
- styles.css — дизайн и адаптация под мобильные экраны
- app.js — темы, интерактивные схемы и уровни объяснения

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.
   Для локального просмотра современный браузер обычно позволяет открыть файл напрямую.
3. Для публикации загрузите все три файла в один репозиторий GitHub и включите GitHub Pages.

Важно:
- Сейчас приложение не использует ИИ, аккаунты, базу данных или собственный сервер.
- При вводе своей темы создаётся универсальная демонстрационная схема, а не автоматически проверенное объяснение.
- Шрифты загружаются с Google Fonts; если подключение недоступно, используется системный шрифт.
- Не добавляйте API-ключи в app.js или другие публичные файлы.
